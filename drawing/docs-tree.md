# Drawing law · Docs tree

Type: Law · docs tree: how it is drawn, in every repo · pulled through rulesindex when drawing a docs tree, together with index-and-legend.md. Update: one rule = one line; replace the line, never add beside it; IDs are append-only.

Answers: which documents exist, what each AI turn loads and pulls, in what order, and each type's cap. The one kind drawn on its own pages, not as a module section, because it maps the documents rather than the system. Seat: architect, `/architecture-ddd-draw`. Standard: the org-structure board and its text copy `HQ-M1-org-structure/sot/doc-tree.md`.

- **DRAW-38 Docs tree.** Drawn on the org-structure standard, never a parallel scheme: nodes are documents only; the shape encodes the doc type (rounded = Law or Card · document = Index · stacked documents = Knowledge, Skill, Template · process = Machinery · cylinder = Data or State · file = Config · chevron = trigger) and the colour encodes the load state (green = exists and loads · blue = not written yet · yellow = pulled by request · purple = outside · white = decision); machinery, data and config are drawn as process, cylinder and file shapes with 0 characters, never as doc nodes. Each node carries name and path · type and how it loads · size today against its type cap. Drift is measured against the global card's caps and the standard's per-seat budgets; sizes are measured from the files, never estimated (board approved 2026-10-11, the law aligned 2026-10-15).
- **DRAW-46 Pages.** On the org standard board, one page each, in this order: doc types · layer flow (index → folder → topic file) · folder structure · size caps · load per seat type (what each AI turn loads and pulls, the characters read on every arrow) · state and change list. On a module or project board, two pages: the method (the standard's types and caps applied to this module, the node card, the flow template, the drift lines) and the instance (the approved docs table and the load flow with running totals). A folder or step is a black-outlined white box, never a doc fill.
- **DRAW-47 Moves with the docs.** Any doc added, moved or renamed updates the docs tree in the same change (figma-law DRAW-7).
